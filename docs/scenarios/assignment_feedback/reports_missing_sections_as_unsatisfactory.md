# Reports Missing Sections As Unsatisfactory

## Purpose

Grade absent report sections.

---

# Context

An assignment feedback workflow is grading a markdown report against the
rubric for the detected assignment.

---

# Action

The uploaded report is missing sections required by the assignment
rubric.

---

# Outcome

The grading response includes explicit unsatisfactory rubric feedback
for each missing required section.
