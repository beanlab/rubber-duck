# Reports Status

## Purpose

Confirm bot health.

---

# Context

The bot is running and admin command routing is available in the
configured admin channel.

---

# Action

An operator sends `!status` in the configured admin channel.

---

# Outcome

The application replies with `I am alive. 🦆`.
