# Forwards Active Thread Messages

## Purpose

Continue active conversations.

---

# Context

A duck conversation is active in a Discord conversation thread.

---

# Action

A non-bot user posts a message in the active conversation thread.

---

# Outcome

The message continues the existing duck conversation. It does not start
a new duck conversation and is not routed as an admin command.
