# Conversation Review Scenarios

Conversation review scenarios describe reviewer workflows for recorded
student conversations.

The shared conversation review context is:

- a duck is configured with `duck_type` set to `conversation_review`
- recorded student conversations may be queued for review
- reviewers score, skip, or comment on queued conversations in Discord threads
- recorded review results are available for later metrics and reporting
